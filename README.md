# Progetto HTML: Il mio viaggio a Londra

### Descrizione

Questo progetto HTML rappresenta una semplice pagina web dedicata al racconto di un viaggio a Londra. La pagina è organizzata in diverse sezioni che permettono di mostrare contenuti multimediali e informazioni utili riguardo il viaggio:

- **Sezione Immagini**: contiene una serie di foto di Londra, sia locali (dal percorso relativo) che remote (da URL esterni), per dare un’idea visiva del viaggio.
  
- **Sezione Le mie spese**: una tabella che riepiloga le spese sostenute durante il viaggio, con descrizione e costo di ogni voce, e un totale finale.

- **Sezione Cose da fare**: una lista puntata con le attività programmate, evidenziando con simboli quali sono già state completate e quali no.

- **Sezione Info utili**: una lista ordinata con informazioni pratiche come numeri di emergenza, dettagli sull’hotel e gli orari dei voli di andata e ritorno.

- **Sezione Le foto**: una seconda galleria di immagini per arricchire ulteriormente il racconto visivo del viaggio.

L’intero progetto è strutturato con un uso basilare di elementi HTML (titoli, immagini, tabelle, liste) per organizzare i contenuti in modo chiaro e leggibile.
